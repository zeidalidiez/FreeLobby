# FreeLobby Craft Materials

These seven source images are the CC0 diffuse maps used by FreeLobby's
runtime craft-texture compositor. The compositor recolors, clips, layers, and
stitches them into avatars, furniture, floors, walls, and interface surfaces.

Every source comes directly from Poly Haven and is released under
[CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/).
Attribution is not required, but provenance is retained in `materials.json`.

The shipped files are unmodified 1K JPG downloads. Runtime derivatives are
generated locally in the browser; FreeLobby does not contact Poly Haven during
normal use.
